# SkillForge
## Forge the programmer you want to become.
SkillForge is an AI-powered coding mento designed to teach people how to think like developers-not just generate code.
Our mission is simple:
Every lesson should leave you knowing something you didn't know before.
We believe programming isn't reserved for geniuses. It's a skill that can be forged with the right mentor.
This repository documents the journey of building SkillForge from the ground up.
